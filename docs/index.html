Moteur de Sauvegarde & PRA pour Hyper-V, Proxmox VE et IMAP

Control plane autonome écrit en TypeScript avec stockage SQLite embarqué (node:sqlite). Chiffrement AES-256-GCM au repos, streaming temps réel bit-à-bit et ordonnancement de rétention natif.

RAM : < 80 Mo DB : SQLite (WAL) Crypto : AES-256-GCM Streaming : GZip Pipe

Déploiement Docker Compose

Fichier docker-compose.yml prêt pour la production avec persistance de la base, des clés de chiffrement et des certificats SSL :

docker-compose.yml YAML 
version: '3.8'

services:
  dalibackup:
    image: blanguedoc/dalibackup-oss:latest
    container_name: dalibackup-oss
    restart: always
    ports:
      - "3000:3000"   # HTTP Console & Redirection 308
      - "3443:3443"   # HTTPS Console & API Agent
    environment:
      - NODE_ENV=production
      - PORT=3000
      - SSL_PORT=3443
      - SSL_ENABLED=true
      - DATABASE_FILE=/app/data/dalibackup.db
      - DEFAULT_LOCAL_STORAGE_PATH=/var/backups/dalibackup
      - TZ=Europe/Paris
    volumes:
      - ./data:/app/data
      - ./backups:/var/backups/dalibackup
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000/api/health"]
      interval: 30s
      timeout: 5s
      retries: 3

Intégration Hyperviseurs & Moteurs

Microsoft Hyper-V

Sauvegarde continue à chaud des disques virtuels (.vhdx / .vhd) via snapshots VSS cohérents avec les applications. Les disques sont compressés à la volée en GZip et streamés vers le serveur de stockage sans création de gros fichiers temporaires locaux.

Proxmox VE (QEMU & LXC)

Support natif de l'API Proxmox 2.0 avec authentification par API Token chiffré. Le hook vzdump permet la réplication et le catalogage automatique dès la fin d'un job Proxmox standard.

Universal IMAP Email Sync

Synchronisation incrémentielle basée sur le pointeur UID pour chaque dossier (INBOX, Sent, etc.). Export au format standard .eml dans une archive .tar.gz immédiatement réimportable.
