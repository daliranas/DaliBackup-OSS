Proxmox VE (Connexion API sans agent)

Déclaration manuelle requise : Cliquez sur "Déclarer un Nœud Proxmox" avec l'IP et le token API (root@pam!dalibackup). Aucun agent n'est requis sur l'hôte Proxmox.

Microsoft Hyper-V (Agent PowerShell)

Auto-découverte automatique : Inutile de déclarer manuellement ! Exécutez simplement le script PowerShell sur votre hôte Windows :

.\DaliAgent-HyperV.ps1 -ServerUrl "http://localhost:3000"

Boîtes Mail & Messagerie IMAP

Sauvegarde incrémentale d'e-mails (RFC822 / .eml) depuis n'importe quel serveur IMAP

Sauvegarde Souveraine & Universelle de Boîtes E-mails

Compatible avec tous les serveurs IMAP (Gmail, Microsoft 365, Dovecot, Zimbra, OVH, cPanel). Les e-mails sont archivés au format standard .eml (RFC822) dans une archive compressée sur vos stockages NFS / SFTP / FTP. Synchronisation incrémentale par UID pour ne télécharger que les nouveaux messages.

💡 Proxmox VE : L'ID est le numéro de VM ou CT (ex: 100). La sauvegarde s'exécute via snapshot non-disruptif.
💡 Boîte E-mail IMAP : Sauvegarde incrémentale par UID et archivage des e-mails au format brut standard .eml (RFC822).
Zstandard (ZSTD) — Recommandé pour Proxmox & Windows :
  • Proxmox VE : Compression multi-threadée native via vzdump --compress zstd (très haut débit, charge CPU optimisée).
  • Windows / Hyper-V : Si zstd.exe est présent sur l'hôte (via Install-Zstandard.ps1 ou winget install Facebook.Zstandard), compression instantanée des fichiers VHDX à la volée. Fallback transparent si non installé.
  • Gain : Réduction de 40% à 70% de l'espace disque avec une vitesse de transfert maximale.
