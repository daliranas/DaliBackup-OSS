## 2025-02-21 - [CRITICAL] Fix Path Traversal in NFS Storage Provider
**Vulnerability:** The NfsProvider (`src/storage/nfsProvider.ts`) allowed arbitrary file writes and reads (Arbitrary File Write / Path Traversal). The method `uploadStream`, `deleteFile`, etc., used `path.isAbsolute(remoteFilePath) ? remoteFilePath : path.join(this.basePath, remoteFilePath)`. Because an authenticated agent/user could specify `remoteFilePath` via headers (e.g. `x-backup-filename: /etc/passwd` or using `../../`), they could bypass `this.basePath` entirely or traverse out of it, reading, deleting, or overwriting any file on the host OS.
**Learning:** `path.isAbsolute` should never be used as a shortcut to bypass a storage base path. Always anchor paths to the base directory and stringently verify they don't escape it.
**Prevention:** Securely resolve file paths against the intended base directory using `path.resolve(this.basePath, remoteFilePath)` and strictly verify that the resulting absolute path begins with `this.basePath + path.sep` (or equals `this.basePath`) to thwart traversal sequences (`../`).
